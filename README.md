# Tatnall current feed

A small, canonical-only companion to the free TatnallLegacy GitHub Pages site. This directory is mirrored to the public `zmmnvt8yxv-dev/tatnall-live` repository. `workflow.yml` becomes `.github/workflows/refresh.yml` there; it is not activated in the private application repository.

- Standard public Ubuntu runners; no paid services, API subscriptions, dependency caches, private repository checkout, or raw-data artifacts.
- Runs every five minutes, offset from the hour. GitHub may delay or drop scheduled runs. A tab checks the published feed every minute while visible; Pages caching/deployment can add delay. This is not instantaneous scoring.
- `SOURCE_MAP` is a base64/zlib-compressed private JSON identity map in GitHub repository secrets. It contains only the configured source coordinates and exact provider-to-canonical mappings. Never log, commit, upload, or display it. The browser verifies its accepted SHA-256 via the companion live manifest.
- Mapping evidence comes from datarepo's migrated canonical `player_ids.parquet`, joined by provider ID and canonical UUID to the accepted public player directory. Current team UUIDs are reproduced from the existing configured namespace and season/league/roster key contract. No display-name joins. All 157 current roster players resolve. Unknown future players are unlinked placeholders; unknown teams or a season change stop publication.
- Only league, NFL state, rosters, current-week matchups and completed current-week transactions are fetched from the documented Sleeper API. Scores honor commissioner overrides; starter slots, team coverage and matchup pairs are checked. No fabricated projection or win-probability updates. Player moves omit pick/budget transfers and disclose that coverage.
- ESPN official NFL RSS headlines, publication dates and unchanged original links are displayed with ESPN attribution. No article bodies, photos, X scraping or paid API. A news-only failure marks news unavailable without suppressing valid scores.
- The successful validated response is deployed atomically as `snapshot.json`. A failed source/validation/deployment retains the previous Pages deployment. Browser errors retain the last verified query result; an initial failure uses the dated website archive. After 15 minutes the source is visibly delayed.
- The site upload contains only the small sanitized feed and `.nojekyll`. One-day artifact retention bounds storage (typically a few MB/day); $0 paid-Actions Stop usage remains required account policy. No 160 MB history rebuild on refresh, no git commit per poll.
- To pause: disable `refresh.yml` in Actions. To roll back: disable the feed workflow, roll the website back to artifact commit `eebbe123140570070395c5139cfc4bf4165eaa33`; archive and exact historical release pins remain unchanged. Re-enable only after tests/source checks pass. GitHub may disable public schedules after 60 days without repository activity; check Actions if the source is delayed.
